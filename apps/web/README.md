# VeriBridge AI Web

Next.js frontend for VeriBridge AI.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- ESLint

## Local Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Checks

```bash
npm run lint
npm run build
```

## Current Scope

This app currently includes a landing page at `/` and a placeholder dashboard at `/dashboard`.

Authentication, AI integrations, and backend API wiring are intentionally not implemented yet.

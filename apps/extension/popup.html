How to record fullscreen video proof:
  1. Open the target from the Website Proof page, then click Start Recording
  2. A recorder tab opens automatically
  3. In the recorder tab: click Start Screen Capture → select Entire Screen
  4. Enter fullscreen on your video/workflow page
  5. Return to recorder tab → click Stop Screen Capture → video uploads
  6. Return here → Stop Recording → Send Proof
VeriBridge records project workflow evidence only. Passwords and sensitive fields are masked.
